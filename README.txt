========================================================
  RAMMIT  -  Roblox Multi-Account Launcher
  Setup Guide (read this first)
========================================================

WHAT IT IS
----------
RAMMIT lets you save multiple Roblox accounts and launch several of
them at the same time on one PC. You do NOT need Python or any other
program installed - everything RAMMIT needs is inside this folder.


WHAT YOU NEED
-------------
  * Windows 10 or Windows 11
  * Roblox installed (get it from https://www.roblox.com/download)


HOW TO INSTALL (3 steps)
------------------------
  1. Right-click the ZIP you downloaded and choose "Extract All...".
     Pick a normal location such as your Desktop or Documents.

  2. Open the extracted "RAMMIT" folder. Keep ALL the files together -
     RAMMIT.exe needs the "src" folder next to it to work. Do not move
     RAMMIT.exe out on its own.

  3. Double-click  RAMMIT.exe  to start.

  (Optional) Right-click RAMMIT.exe > "Send to" > "Desktop (create
  shortcut)" so you can launch it easily later. Move the SHORTCUT to
  your desktop, not the .exe itself.


FIRST TIME YOU RUN IT
---------------------
Windows may show a blue box that says
    "Windows protected your PC".
This appears for any new app that is not code-signed. It is safe to
continue:
    -> click "More info"
    -> click "Run anyway"

RAMMIT will open its own window and walk you through adding your first
account. Your accounts and settings are saved automatically inside a
"Config" folder that RAMMIT creates next to RAMMIT.exe.


HOW TO USE
----------
  * Add an account:   follow the on-screen tutorial the first time,
                      or use the "Add Account" button.
  * Launch accounts:  select one or more saved accounts and press
                      Launch. Set how many can run at once in Settings.
  * Everything is stored locally on your PC only.


PRIVACY / SECURITY
------------------
  * RAMMIT stores your account logins locally in Config\accounts.json.
    That file contains sensitive login tokens - never share it, and
    never share your RAMMIT folder after you have added accounts.
  * This download ships with NO accounts saved. You start fresh.


TROUBLESHOOTING
---------------
  * "It won't open / nothing happens":
      Make sure RAMMIT.exe and the "src" folder are in the SAME folder.
      Some antivirus tools block new apps - allow RAMMIT if prompted.
  * "SmartScreen keeps blocking it":
      See "FIRST TIME YOU RUN IT" above (More info -> Run anyway).
  * "Accounts won't launch":
      Make sure Roblox is installed and you can open it normally first.


Enjoy RAMMIT.
