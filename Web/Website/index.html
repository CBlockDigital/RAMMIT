QuestionsNo. 09

FAQ

quick answers.

Is RAMMIT free?

Yes. RAMMIT is a free Windows app.

What do I need to run it?

Windows 10 or 11. Download RAMMIT-Setup.exe and run it; it installs RAMMIT and can update or remove it later. Prefer no installer? Grab the zip from the releases page, unzip it and run RAMMIT.exe. Python isn't needed either way.

Where are my accounts stored?

Only on your own PC, inside the RAMMIT folder.

Does it work with Bloxstrap or Fishstrap?

Yes. Pick Roblox, Bloxstrap or Fishstrap as your launcher in Settings.

Can I see the code?

Yes. RAMMIT is on GitHub, along with every release and its SHA-256 checksum.

Can I get everyone into the same server?

Yes. Launch with Place ID + Job ID for an exact server, or with a VIP / private-server link.

Does it farm, auto-play or run scripts?

No. RAMMIT only opens multiple official Roblox clients. What you do in them is up to you.

Is RAMMIT made by Roblox?

No. RAMMIT isn't affiliated with Roblox Corporation.
